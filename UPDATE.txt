DEPLOYMENT

1. Upload the website files to the existing GitHub repository, including the .github folder.
2. Replace code.gs in the existing Apps Script project and redeploy it at the same web-app URL.
3. Existing Google Sheet columns and product data do not need to be removed or reordered.

SIZES AND PRICE PER SIZE

- In Admin, enable “This product requires size selection”.
- Enter comma-separated sizes, for example: 32B, 34B, 36B.
- The normal Price is used for every size unless an override is entered.
- In “Price per size”, enter only exceptions, for example: 32B=299, 34B=329.
- Customers must choose a size before adding the product to the cart.
- The selected size and its price are revalidated by Apps Script during checkout.
- Stock quantity is shared across all sizes of that product.

PHOTO EFFECT

Product-card photos now use a subtle zoom on pointer hover and a smaller touch response. The effect respects reduced-motion settings and keeps images uncropped.

SEO AND PUBLISHING

The GitHub workflow continues to build crawlable category, product, Hindi and sitemap pages from the live catalogue. Product structured data includes size-specific offers when price overrides exist.

After deployment, submit https://suhagbhandar.in/sitemap.xml in Google Search Console and test one generated product URL with Google Rich Results Test.
