WHAT CHANGED

Customer flow
- Invalid checkout details return to an editable form rather than a retry loop.
- Uncertain order attempts retain their request IDs and duplicate-safe recovery.
- All copies of a product and the cart badge update together after cart changes.
- Cart quantity edits no longer discard catalogue pages already loaded.
- Cart removals, quantity reductions and price changes are explained in the drawer.
- Search no longer silently filters category browsing; browsing filters persist in the URL.
- Search buttons on product/information pages open homepage search directly.
- Tracking supports Pending, Confirmed, Packed, Shipped, Delivered, Fulfilled and Cancelled.

Appearance and information
- Compact brand-only hero, followed immediately by categories and products.
- Full-product photos in listing cards; portrait images are no longer cropped to squares.
- Desktop product image/details layout; preserved adaptive gallery on phones.
- Delivery/COD charges are shown on product pages when live fee settings are available.
- Gallery dots and keyboard arrows select photos.
- Hindi switching preserves review drafts and does not reload reviews unnecessarily.
- Order acknowledgement distinguishes receipt of the order from payment verification.
- Order slip can be downloaded as HTML or printed/saved as PDF through the browser.
- UPI QR codes are generated locally. The QR library loads only for UPI confirmation;
  the UPI-app link and UPI ID remain available if it cannot load.
- Automatic install suggestions wait for a return visit and avoid open dialogs.
  An explicit Add shop to Home Screen control remains available in the footer.

Efficiency and operations
- Same-origin catalogue snapshots can display before a slow live catalogue response.
- Cached/snapshot availability is clearly distinguished from live checkout validation.
- Live data replaces the saved catalogue in the background; expired snapshots are rejected.
- Review summaries, product reviews and checkout settings reuse short-lived session data.
- Cloudinary resizing supports versioned and versionless folder URLs.
- Admin product edits batch adjacent changed cells without rewriting unrelated formulas.
- Stock updates reuse validated product data and batch consecutive changed rows.
- Admin order responses return 40 filtered records per page; dashboard charts use server totals.
- Older admin clients can still request the original unpaged order response.
- Admin dashboard displays Telegram queue count and last-run/success information.
- Public product responses explicitly allow customer fields only, including in build snapshots.
- Publishing can reuse a validated catalogue snapshot up to 24 hours old during an API outage.
  Snapshot timestamps are preserved; an outage does not falsely make old data fresh.
- Static catalogue links remain visible if live availability cannot load.
